# 界面设计稿（定稿）

在线版：https://claude.ai/artifact/5zonia8MsnbEXKYhfCCrwr

| 文件 | 内容 |
|---|---|
| `Main.dc.html` | 主界面（已连接）：左侧状态栏、会话标签、终端（含“外观”面板）、命令栏、底部文件 / 快捷命令 / 历史 / 传输 |
| `NewTab.dc.html` | 新标签页：快速连接 |
| `Manager.dc.html` | 连接管理器（Finder 式文件夹树）+ 新建 / 编辑连接弹窗 |

这些是设计工具的源文件（HTML + 内联样式 + 一段生成示例数据的脚本），正式界面以它们的视觉和交互为准，示例数据除外。

定下的原则：交互照搬 FinalShell，外观是 Mac 原生风格；默认跟随系统深浅色；终端背景可在“外观”面板里换预设或自定义。

## 正式界面和设计稿的差异

代码在 `packages/ui`，以下几处是有意不同：

- 桌面窗口用系统自带的红黄绿按钮，界面里不画假按钮；状态栏顶部留出同样高度的空白，和标签栏对齐。
- 云同步（所有者 2026-10-28 选了方案 A）：左上角「同步状态」没开同步时写「未开启」，单击打开同步窗口（登录 / 注册账号）；开了以后单击直接打开同步窗口（状态、立即同步、已登录的设备、修改同步密码、退出登录）。右上角菜单里也有「云同步…」。设计稿：https://claude.ai/artifact/NDmqP3LDsJnQrT4uELxsbh ，做法见 [docs/specs/sync.md](../specs/sync.md)。
- 文件区的目录树是真正可展开的树，设计稿里是扁平的路径列表。
- 选中标签的文字颜色随终端底色取对比色，避免深色界面配浅色终端预设时看不清。
- 路径框可以直接输入路径回车跳转；底部面板高度可以拖动调整。
- 状态栏右侧只显示延迟，服务器版本暂时拿不到。
- “跟随终端目录”依赖终端发出 OSC 7 或窗口标题里的路径；服务器上的 shell 没配置时不会跟随。
- 连接管理器的服务器行在名称栏右边多了齿轮按钮（鼠标指到或选中时出现），点它编辑这台服务器；设计稿里没有。
- 连接管理器和底部文件区选中一行时，文件夹和服务器图标保持原色，不像设计稿那样变白（所有者 2026-10-23 定）。
- 新建连接里的“高级”“端口转发”目前只保存，不生效。
- 认证方式只有「密码」「公钥」，设计稿里的「密钥库」去掉了：选「公钥」时点「选择…」从私钥库里选，照 FinalShell（所有者 2026-10-25 选的方案 A）。设计稿：https://claude.ai/artifact/Sc2TUsbjVw2f8uRvpptcrD ，做法见 [docs/specs/key-library.md](../specs/key-library.md)。和设计稿不同的地方：导入时私钥一栏沿用原来的「选择…」加粘贴框；改名、删除用通用的输入框和确认框。
- 状态栏进程表的「内存」「CPU」表头可以点，按这一列从高到低排，选中的那列字变亮、带小箭头；默认按内存，选择会记住。
- 标签宽度随文字（最长 240px，再长省略），设计稿里一样宽（所有者 2026-10-23 定）。
- 状态栏的「系统信息」按钮、进程表的表身、网速图各打开一个标签页（系统信息 / 进程 / 网络），不再弹系统信息小框。会话和它的这几页组成 Chrome 式标签组：带颜色的名字块、底下一条同色的线、选中的标签描一圈同色的边，点名字块收起。设计稿：https://claude.ai/artifact/Nc4tRntjx3Nb4DhHfNbf1N ，做法见 [docs/specs/monitor-tabs.md](../specs/monitor-tabs.md)。
- 底栏只剩「文件」「命令」两页，「历史命令」「传输」去掉了（所有者 2026-10-23 定）。设计稿：https://claude.ai/artifact/TwkhWsTaeeXyQYcM6ccNgM 。和这份设计稿不同的地方：
  - 编辑器是单独的窗口（所有者选的）；设计稿里浮在主窗口上。网页端没有单独窗口，仍然浮在主窗口上。
  - 单击命令直接发送（所有者选的，和 FinalShell 一样）；设计稿是单击选中、双击发送。点过的命令不变色，只在按下去时深一下（所有者 2026-10-23 定）；底部「发送」再发一次最近发过的那条，鼠标停上去会写是哪条。
  - 分类上有右键菜单「重命名…」「删除…」；齿轮按钮有悬停提示「编辑」；编辑命令弹窗的分类是下拉框。
  - 命令编辑器为空时，「存为快捷命令…」「清空」是灰的。发送失败的提示是橙色。
  - 传输按钮只在有上传下载记录时出现，按钮上写的是正在传的个数和总进度，都传完了只写「传输」。
  - 双击打开文件时，那一行的大小一栏变成「打开中 45%」，底下一条进度线；编辑器保存、重新载入时，状态前面有一条进度和百分比（所有者 2026-10-23 要的，网络慢时不至于以为没点上）。
- 桌面端的连接管理器是单独的窗口（所有者 2026-10-23 定），顶上一条和主窗口标签栏一样高的标题栏，下面和弹窗内容一样；网页端仍是弹窗。做法见 [docs/specs/manager-window.md](../specs/manager-window.md)。
- 快捷命令的「不自动回车」和导入（所有者 2026-10-25 选了方案 A：命令页里单独导入）。设计稿：https://claude.ai/artifact/FB653rR7AssV7KPGsUhXgm ，做法见 [docs/specs/command-import.md](../specs/command-import.md)。和设计稿不同的地方：命令区的右键菜单里也有「导入快捷命令…」；预览里多了「有特殊写法」的标签（来源专用、EverShell 做不到的写法，默认不勾）；完整命令放在命令那一栏的悬停提示里。
- 文件区的拖入上传、多选、快捷键和右键菜单（所有者 2026-10-26 定：滑动选择用方案 A，按住拖过的行连成一段；右键菜单照 FinalShell，去掉「打开方式」「选择文本编辑器」）。设计稿：https://claude.ai/artifact/4HJjh8jzi287ZC8T84S8nL 。和设计稿不同的地方：
  - 右键菜单不用设计稿里画的三份，改照 FinalShell 的顺序：刷新｜打开｜复制路径｜下载、上传…｜新建 ▸（文件夹…、文件…）｜重命名…、删除…。点在空白处是同一份菜单，用不了的项变灰；选中多项时「打开」「重命名…」变灰，选中的含文件夹时「下载」变灰（下载文件夹还没做）。FinalShell 菜单里的「打包传输」「快速删除（rm 命令）」「文件权限…」要在服务器上执行命令、改权限，放到第二批，做好前不放进菜单。
  - 快捷键多了「复制路径」；设计稿底下的「已选中 N 项」和按键反馈只是演示用，正式界面没有。
  - 拖进来的文件夹里的 `.DS_Store`（访达自己的记录文件）不上传。

  文件区快捷键（单击文件列表后生效，不影响终端；实现在 `packages/ui/src/core/platform.ts` 的 `fileKeyAction`）：

  | 操作 | Mac | Windows / Linux |
  |---|---|---|
  | 上下移动、连续选择 | ↑↓、⇧↑↓、⇧ 单击、按住拖动 | ↑↓、Shift+↑↓、Shift+单击、按住拖动 |
  | 加选或取消一项 | ⌘ 单击 | Ctrl+单击 |
  | 全选、取消选择 | ⌘A、Esc | Ctrl+A、Esc |
  | 第一项、最后一项 | Home、End | Home、End |
  | 按名称跳转 | 直接输入名称开头的字符 | 同左 |
  | 打开文件夹或编辑文件 | ⏎、⌘↓ | Enter |
  | 返回上级目录 | ⌘↑、⌫ | Alt+↑、Backspace |
  | 重命名 | F2 | F2 |
  | 删除（先确认） | ⌘⌫、Delete（fn⌫） | Delete |
  | 新建文件夹 | ⇧⌘N | Ctrl+Shift+N |
  | 刷新 | ⌘R | F5、Ctrl+R |
  | 复制路径 | ⌥⌘C | Ctrl+Shift+C |
  | 转到路径框 | ⌘L | Ctrl+L |
- 第二批（文件权限、快速删除、打包传输、下载文件夹）：文件权限弹窗用设计稿方案 A（所有者 2026-10-26 选的），做法见 [docs/specs/file-ops.md](../specs/file-ops.md)。网页版没有打包传输，也不能下载文件夹。
