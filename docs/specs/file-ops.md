# 文件区第二批：文件权限、快速删除、下载文件夹、打包传输

> 2026-10-26。所有者要文件区的右键菜单和 FinalShell 一样（去掉「打开方式」「选择文本编辑器」），文件权限弹窗用设计稿的方案 A。第一批（拖入上传、多选、快捷键、菜单重排）已经做完，这一份是剩下要在服务器上执行命令、改权限、往本机写文件夹的几项。

设计稿：https://claude.ai/artifact/4HJjh8jzi287ZC8T84S8nL （最下面一排）

## 做什么

| 菜单项 | 做法 | 平台 |
|---|---|---|
| 文件权限… | SFTP 改权限（setstat）。文件夹可以连同里面的内容一起改，范围选「文件和文件夹 / 仅文件夹 / 仅文件」 | 全部 |
| 快速删除（rm 命令）… | 在服务器上执行一条 `rm -rf`，比逐个经 SFTP 删快得多 | 全部 |
| 下载（文件夹） | 逐个经 SFTP 下载，在本机「下载」文件夹里建同名文件夹 | 桌面端；浏览器写不了文件夹，网页端选中文件夹时「下载」仍是灰的 |
| 打包传输 | 服务器上用 tar 打成 .tar.gz → 下载 → 本机自动解压到「下载」文件夹 → 删掉服务器上的临时包 | 桌面端；网页端不显示这一项 |

打包传输适合文件多、单个小的情况（一个 `node_modules`），省掉每个文件一次往返。服务器上要有 `tar` 和 `gzip`（Linux 和 macOS 都自带）。

## 接口（`packages/ui/src/types.ts`）

- `FileEntry` 加 `group`：用户组名，拿不到时是 gid 数字。来源同 `owner`：属性里的名字 → readdir 的 longname 第 4 列 → gid。
- `SshSession.chmod(path, mode, scope)`：`mode` 只取低 12 位（含 SUID、SGID、粘滞位）。`scope`：
  - `self`：只改 path 本身；
  - `all` / `dirs` / `files`：path 是文件夹时连同里面的内容，分别是全部、只改文件夹（含它自己）、只改文件（不含它自己）。path 不是文件夹时三者都等于 `self`。
- `SshSession.removeFast(paths)`：paths 是绝对路径。
- `SshSession.downloadDir?(path, onProgress)`：返回本机文件夹路径。
- `SshSession.packDownload?(dir, names, onProgress)`：names 是 dir 里的名字，返回解压出来的每一项的本机路径。打包这一步没有进度，回调里 `total` 为 0；下载开始后照常报进度。

服务器命令只在 Rust 内核里拼（`crates/ssh-core/src/remote_cmd.rs`），界面只传路径和名字，不传命令。

## 安全

服务器给的文件名、打包下来的压缩包都是不可信输入（[security.md](../handbook/security.md#红线)）。

**拼命令**

- 每个参数都用单引号包起来，里面的 `'` 写成 `'\''`；单引号里什么都不展开（`$`、反引号、换行都只是字），sh、bash、zsh、fish、csh 都认这种写法。
- 参数前面加 `--`，以 `-` 开头的文件名不会被当成选项。
- 路径必须是绝对路径，不能是 `/`，不能含 `.`、`..` 段和 NUL；名字不能为空、不能是 `.` `..`、不能含 `/` 和 NUL。不合格的整条命令不执行，直接报错。
- 打包用的脚本整个交给 `sh -c`，路径和名字作为 `$1`、`$2`… 传进去，不拼进脚本正文；登录 shell 是 fish 之类不认 `$(…)` 的也能跑。
- 服务器上的临时包用 `mktemp` 建在 `${TMPDIR:-/tmp}`，先 `umask 077`，只有登录用户自己能读；下载完删掉，打包失败也删。

**改权限**：递归时不跟进符号链接（SFTP 的 setstat 会顺着链接改到别处去），链接本身也不改。文件夹先改里面的、最后改它自己，免得先把自己改成不可读，里面就列不出来了。

**下载文件夹**：服务器给的名字含 `/`、是 `.` `..`、含 NUL 或者（Windows 上）含本机不允许的字符的，跳过不下，免得写到「下载」文件夹外面。符号链接跳过。本机建的文件夹重名时加序号（`nginx (1)`），不覆盖本机已有的东西。

**解压**（`apps/desktop/src-tauri/src/unpack.rs`）：

- 只解普通文件和文件夹；符号链接、硬链接、设备文件、FIFO 一律跳过。
- 路径的每一段都必须是普通的名字：不能是绝对路径、`..`、盘符。
- 先解到「下载」文件夹里一个新建的隐藏临时文件夹，解完把最上一层的每一项挪到「下载」文件夹，重名加序号，再删掉临时文件夹。本机已有的同名文件不会被覆盖。
- 权限去掉 SUID、SGID、粘滞位，组和其他人的写权限也去掉（`mode & 0o755`）。

## 测试

- 内核：`remote_cmd.rs` 的单元测试（引号、`--`、各种不合格的路径和名字）；连测试服务器（`scripts/test-sshd.sh`）测改权限的三种范围、符号链接不受影响、快速删除带空格和引号的名字、打包命令能打出包。
- 桌面端：`unpack.rs` 用造出来的坏包测：带 `..` 的、绝对路径的、符号链接的、重名的。
- 界面：`core/permissions.ts`（`drwxr-xr-x` 和数字互转、SUID 这些位）有单元测试；弹窗在网页版 `?mock` 里看深浅色。
