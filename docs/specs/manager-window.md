# 连接管理器做成独立窗口

> 2026-10-23。所有者要求连接管理器“做成和编辑器一样类型的窗口”。

## 问题

连接管理器现在是主窗口里的弹窗，挡着终端，也拖不出主窗口。编辑器已经是独立窗口（[remote-edit.md](remote-edit.md)），所有者要连接管理器也一样。

## 方案

### 界面

- 桌面端：点标签栏左边的文件夹图标、≡ 菜单的「连接管理器…」「导入连接…」、⌘O，打开独立的「连接管理器」窗口（标签 `manager`），同一时刻只有一个，已经开着就切到前面。窗口顶上是一条和主窗口标签栏一样高的标题栏，中间写「连接管理器」，按住能拖；下面的内容和原来的弹窗一样。
- 在里面点「连接」：连接在主窗口里开（要密码的话密码框也在主窗口弹），主窗口切到前面；勾着「连接后关闭窗口」就把管理器窗口关掉。
- 新建、编辑、导入连接的小弹窗在管理器窗口里面弹。
- 主窗口关掉时，管理器窗口一起关。
- 打开要快：新建一个窗口要启动一个网页、把界面代码加载一遍，所有者觉得“这么一点东西还要加载”（2026-10-23）。所以主窗口启动 1.5 秒后就在后台把管理器窗口建好、藏着（`manager_window_preload`），点开只是亮出来；关掉（红点、⌘W、连接后自动关）也只是藏起来，下次一样快。代价是常驻多一个网页进程，几十 MB 内存。
- 网页端没有第二个窗口，照旧是主窗口里的弹窗。

### 两个窗口共用本地数据

窗口各有一份内存里的数据（`PersistentStore`），硬盘上是同一份。以前只有一个窗口，没问题；现在管理器窗口改了连接列表，主窗口内存里还是旧的，主窗口下次写（比如连上后记“上次连接时间”）就会把管理器的修改盖掉。

做法：`core/storage.ts` 的 `PersistentStore` 每次写完，把“键 + 新内容”广播给其他窗口；收到的窗口直接换成这份内容（按原来的规则校验），不再写回、不再广播。所有存储键都这样，外观设置、编辑器的偏好也跟着各窗口同步。

- 桌面端广播走 Tauri 事件 `store-sync`，带上发出的窗口标签，自己发的不处理。接口是 `types.ts` 的 `StorageSync`，在 `apps/desktop/src/main.tsx` 接上。
- 浏览器自带的 `storage` 事件也接上：网页版开了两个页签时一样能同步。
- 两个窗口几乎同时改同一个键，后写的那份赢。连接管理器和主窗口同时改连接列表的机会很小，先不处理；M2 做同步时记录级的合并一起解决。

### 两个窗口之间的消息

| 方向 | 消息 | 内容 |
|---|---|---|
| 主 → 管理器 | `hello` | 主窗口刚启动，管理器已经开着的话回 `ready` |
| 主 → 管理器 | `import` | 打开后直接进导入（≡ 菜单的「导入连接…」） |
| 管理器 → 主 | `ready` | 管理器窗口加载好了，主窗口把攒着的消息发过去 |
| 管理器 → 主 | `connect` | 要连的服务器 id，几台时按顺序 |
| 管理器 → 主 | `gone` | 管理器窗口没了（Rust 发） |

### 接口

- `SshBackend.managerWindow?: WindowLink`（和编辑器共用 `WindowLink`：`open` / `post` / `listen`）；管理器那头是 `ManagerWindowHost`（`post` / `listen` / `close` / `focusMain`）。
- Rust：`windows.rs` 里 `manager_window_open`、`main_window_focus`；打开窗口时带上界面现在的底色（`WindowLink.open(background)`），网页画出来之前先露出这个颜色，深色模式下不会先白一下（[pitfalls.md](../handbook/pitfalls.md#新开的窗口先白一下2026-10-23)）；窗口销毁时发 `gone`；主窗口关闭时把管理器窗口一起关掉。`capabilities/manager.json` 给管理器窗口 `core:default`、拖动、关闭的权限。
- 调试版加了环境变量 `EVERSHELL_OPEN=manager`：启动 4 秒后（主窗口已经把它预先建好）把管理器窗口亮出来，给截图看样子、看预先建好的窗口是不是一亮就有内容，正式版里没有。

## 数据

存储格式不变。

## 对其他平台的影响

- 网页端：照旧是弹窗；多开页签时数据能同步了。
- Windows：一样能开第二个窗口。
- 手机：以后做成一页，用同一个组件。

## 怎么测

- 单元测试：`PersistentStore` 收到别的窗口的内容后更新、不回写不再广播；`ManagerLink` 攒消息、收到 ready 再发、按顺序连接。
- 网页版 `?mock`：弹窗照旧能用。
- 桌面端：`EVERSHELL_OPEN=manager` 开调试版截图看窗口；连接、拖动、两边数据是否同步请所有者试。
